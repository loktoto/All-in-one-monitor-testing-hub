# 去重能力目錄：優點、MVP 落差與優先次序

內容調查日期：2026-11-13；文件及連結狀態覆核：2026-11-15。這是 44 項彼此可獨立驗收的能力，不是 44 個已完成或承諾交付的功能。「借鑑」欄代號對應[一手來源產品目錄](01-product-evidence.zh-Hant.md)；產品記錄的優點與本表提出的實作方式不可混為一談。**「現況」欄是 2026-11-13 的研究快照；後續實作請以[目前能力清單](../capabilities.md)及程式碼為準**。P0／P1／P2 是建議排序，P0 不是「已實作」；實際安排取決於平台驗證與使用者需求。

標記：**已有**＝MVP 有明確功能，但仍受平台限制；**部分**＝只有較窄子集；**未有**＝不能由現況推斷具備。部分／已有均不代表與來源產品等價。P0：可信讀值、基本可控與安全邊界；P1：核心診斷實用性與可重現性；P2：擴展或高風險能力。

## 當前 MVP 的明確邊界

CPU、RAM、OS 磁碟區與 GPU adapter 可從真實來源讀取；NVIDIA 可在 NVML 可用時讀取 GPU 負載、溫度、VRAM。這不是跨廠商完整硬體監測：無 AMD／Intel GPU 負載／溫度／VRAM，無 CPU／RAM／磁碟溫度或 SMART，也無自動過熱停測。CPU 檢查的參考值同一程式運行時計算；RAM 只涵蓋程序配置；磁碟只用自建暫存檔，總寫入不超過 1 GiB，但可能命中快取並造成 SSD 耗損。GPU 是輕量 compute 驗證而非圖形壓力測試。Windows CI 建置及測試成功不代表已在實體 Windows 硬體或實體 GPU 驗證。
