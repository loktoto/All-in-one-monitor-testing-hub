## Responsiveness and layout

- Compact Overview puts CPU, RAM, GPU, storage, network, temperature and fans in one navigable summary. More detailed sections open beneath it or on the corresponding page.
- Windows can list adapters without initializing each GPU for compute, and the shader compiler has a size-focused release profile. The Windows CI job records the portable executable size.
- Frame Analysis performs file loading and parsing on a worker. It reuses the CSV record buffer, tracks optional metrics without per-sample allocations, and draws at most 480 points. Capture-wide statistics use every valid interval.

The [capability inventory](../capabilities.md) describes platform and device prerequisites. This matrix covers documented functions of the selected products, including features that require specific drivers, hardware, services or boot environments.
